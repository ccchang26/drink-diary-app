# drink-diary-app
# 🧋 手搖日記 Shake Diary

一個記錄手搖飲料的個人日記 App。純前端、單一 HTML 檔案，不需要安裝、不需要伺服器，資料存在你的裝置裡。

## 功能特色

### 📝 紀錄
- 記錄日期、店家、品項、甜度、冰塊、價錢
- 輸入店家後，會自動列出你在這家店最常點的品項，點一下就帶入
- 即時估算這杯飲料的熱量，以及需要慢跑幾分鐘才能消耗掉
- 如果這杯是別人請客，可以標記「別人請的」，這杯就不會計入花費與平均單價

### 📖 歷史
- 依日期分組列出所有紀錄
- 每筆紀錄顯示甜度、冰塊、熱量標籤
- 可以滑動刪除任何一筆紀錄

### 📊 統計
- 總杯數、總花費、本月花費、平均每杯
- 總熱量、本月熱量、換算成慢跑分鐘數
- 最常喝的店家 / 品項排行榜，可切換「本週／本月／今年／全部」統計區間

### 🙌 忍住了
- 今天沒喝手搖飲的話，按下打卡按鈕
- 隨機出現一句鼓勵小語
- 顯示這個月忍住了幾次、估計省下多少錢
- 每天只能打卡一次，避免重複計算

## 使用方式

這是一個單一 HTML 檔案，用瀏覽器打開就能使用。

**在 iPhone 上加入主畫面（像 App 一樣使用）：**
1. 把 `手搖日記.html` 傳到 iPhone（建議放進 iCloud Drive）
2. 用 **Safari** 打開這個檔案
3. 點分享按鈕 → 「加入主畫面」
4. 完成後主畫面會出現一個獨立圖示，點開全螢幕顯示，沒有網址列

## 資料儲存

所有紀錄都存在瀏覽器的 `localStorage`，只綁定在「這個檔案 + 這個瀏覽器」上：
- 清除瀏覽器資料、換裝置、或改用不同方式重新開啟檔案，資料可能會不見
- 建議固定用同一份檔案（或同一個網址）開啟並加入主畫面，之後都用那個圖示進去記錄

## 熱量估算說明

熱量是依品項關鍵字（奶茶、咖啡、清茶、加料等）搭配甜度比例做的粗略估算，僅供參考，不是精確的營養標示。慢跑消耗分鐘數則以每分鐘約 10 大卡的中等強度估算。

## 技術

- 純 HTML / CSS / JavaScript，無任何框架或建置流程
- 使用 Google Fonts（Noto Serif TC / Noto Sans TC）
- 資料儲存：`localStorage`
